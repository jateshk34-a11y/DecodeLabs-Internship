Expense Tracker 💰

A simple Python Expense Tracker that allows users to enter multiple expenses and calculates the total amount spent.

📌 Features

- 💵 Enter multiple expenses
- 🔢 Specify the number of expenses
- ➕ Automatically calculate total spending
- 📊 Display the total number of expenses
- 💰 Display the total amount spent
- 🧾 Show the final expense summary

🛠️ Technologies Used

- Python 3
- "input()"
- "float()"
- "for" loop
- "range()"
- Variables
- Arithmetic operators
- Formatted strings

▶️ How to Run

1. Make sure Python 3 is installed.
2. Open Command Prompt or Terminal.
3. Navigate to the project folder.
4. Run the Python file:

python expense_tracker.py
