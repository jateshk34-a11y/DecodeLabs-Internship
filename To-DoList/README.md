# To-Do List 📝

A simple **Python To-Do List application** that allows users to add, view, and delete tasks from a list.

## 📌 Features

- ✅ Add a new task
- 👀 Show all tasks
- 🗑️ Delete a task by task number
- 🚪 Exit the application
- 🔄 Menu runs continuously until the user chooses Exit

## 🛠️ Technologies Used

- Python 3
- Lists
- `while` loop
- `if-elif-else`
- `input()`
- `append()`
- `del`

## ▶️ How to Run

1. Make sure Python is installed.
2. Open Command Prompt or Terminal.
3. Navigate to the project folder.
4. Run the Python file:

```bash
python todo.py
